# 20 כלים אופליין 🧰

קובץ HTML יחיד הכולל 20 כלים שימושיים שעובדים **ללא חיבור לאינטרנט**.  
פתח את `index.html` בכל דפדפן מודרני – אין צורך בשרת, התקנה, או חיבור לרשת.

## רשימת הכלים

| # | כלי | תיאור |
|---|-----|--------|
| 1 | 🔢 מחשבון | חישובים מתמטיים + פונקציות (sin, cos, sqrt, log...) |
| 2 | 📐 ממיר יחידות | אורך, משקל, טמפרטורה, שטח, מהירות, נתונים, נפח, זמן |
| 3 | ⏱️ שעון עצר וטיימר | שעון עצר עם laps + טיימר עם צליל |
| 4 | 📝 פתקים | עורך טקסט חינמי שנשמר ב-localStorage |
| 5 | ✅ רשימת משימות | To-Do List עם שמירה מקומית |
| 6 | 🔐 מחולל סיסמאות | סיסמאות אקראיות עם אינדיקטור חוזק |
| 7 | 🎨 בחירת צבע | HEX / RGB / HSL עם היסטוריית צבעים |
| 8 | 🔄 Base64 | קידוד ופענוח Base64 |
| 9 | 📋 JSON פורמטר | עיצוב, דחיסה, ואימות JSON |
| 10 | 📄 Markdown תצוגה מקדימה | עריכת Markdown עם תצוגה בזמן אמת |
| 11 | 📊 מונה מילים | תווים, מילים, שורות, משפטים, זמן קריאה |
| 12 | ⚖️ מחשבון BMI | חישוב מדד מסת גוף עם קטגוריה |
| 13 | 🎂 מחשבון גיל | גיל מדויק בשנים/חודשים/ימים |
| 14 | 💱 המרת מטבע | 30 מטבעות עם שערים קבועים |
| 15 | 🔍 בודק Regex | בדיקת ביטויים רגולריים עם הצגת התאמות |
| 16 | 📱 מחולל QR Code | יצירת QR מכל טקסט/URL + הורדה |
| 17 | 🖼️ כלי תמונה | שינוי גודל תמונה + שמירת יחס ופריסה |
| 18 | 🔀 השוואת טקסט | Diff שורה-שורה עם הדגשת הבדלים |
| 19 | 📡 קוד מורס | תרגום טקסט ↔ מורס + נגינה |
| 20 | 🍅 פומודורו | טיימר פומודורו עם זמני עבודה/הפסקה מותאמים |

## שימוש

1. הורד / שכפל את הריפוזיטורי
2. פתח את `index.html` בדפדפן
3. הכל עובד אופליין לחלוטין!
